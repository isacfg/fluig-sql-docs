# Código de Conduta

Queremos uma comunidade em que pessoas com diferentes níveis de experiência possam perguntar, corrigir e contribuir com respeito.

## Comportamento esperado

- Discuta ideias e evidências de forma construtiva.
- Aceite correções e explique divergências com exemplos verificáveis.
- Respeite diferenças de experiência, identidade e contexto.
- Preserve a privacidade de usuários, clientes e participantes.
- Mantenha issues e pull requests relacionados ao projeto.

Assédio, ataques pessoais, discriminação, exposição de informações privadas e spam não são aceitos. Os mantenedores podem editar ou remover conteúdo, encerrar discussões e restringir a participação em caso de violação.

## Relatos

Para conteúdo abusivo, use os mecanismos de denúncia do GitHub e solicite a intervenção dos mantenedores na discussão pertinente, sem repetir dados privados. Relatos sensíveis devem ser feitos por um canal privado já acordado com um mantenedor; peça um canal de contato sem publicar detalhes sensíveis.

Este código se aplica às issues, pull requests e demais espaços de colaboração deste repositório.
