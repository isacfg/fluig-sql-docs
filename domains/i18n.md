## FDN_BUNDLEVALUE

Valores traduzidos de resource bundles (i18n) por bundle, chave e locale. Cada linha é uma tradução de uma chave.

**Ciclo de vida:** Carregada/atualizada na instalação ou atualização de módulos; volume potencialmente alto (milhares de chaves por locale).

**Atenção:** Sem tenant. Distinta de FDN_LITERAL, que guarda customizações de literais por produto/locale.

**PK:** BUNDLE_VALUE_ID

| Coluna | Tipo | Null | Finalidade | Valores | Ref |
|---|---|---|---|---|---|
| 🔑 `BUNDLE_VALUE_ID` | bigint | N | Chave primária da tradução. |  |  |
| `BUNDLE_CODE` | varchar(255) | N | Código do resource bundle ao qual a chave pertence. |  |  |
| `RESOURCE_KEY` | varchar(4000) | N | Chave do recurso de texto dentro do bundle (até 4000 caracteres). |  |  |
| `LOCALE` | varchar(10) | N | Locale da tradução (ex.: pt_BR, en_US, es). |  |  |
| `RESOURCE_VALUE` | varchar(4000) | N | Texto traduzido para a chave e o locale. |  |  |

**Dicas de consulta:** Buscar por (BUNDLE_CODE, LOCALE, RESOURCE_KEY).

## FDN_LITERAL

**Ciclo de vida:** Carga inicial por produto; CUSTOM_VALUE alterado por administradores.

**Atenção:** Sem tenant. CUSTOM_VALUE nulo significa sem customização. Índice (LOCALE, PRODUCT_CODE).

**PK:** LITERAL_ID

| Coluna | Tipo | Null | Finalidade | Valores | Ref |

| 🔑 `LITERAL_ID` | bigint(20) | N | Chave primária. |  |  |

| `LAST_UPDATE_DATE` | datetime | S | Data/hora da última alteração. |  |  |
| `LOCALE` | varchar(8) | S | Locale do literal. |  |  |

## I18N_BUNDLE

Bundle de internacionalização: agrupador de locales e literais traduzidos identificado por código.

**Ciclo de vida:** Criado ao registrar um bundle; baixo volume.

**Atenção:** IDs são UUID em varchar(36). Unique key (artefato UNIQUE) provavelmente em BUNDLE_CODE.

**PK:** BUNDLE_ID · **Unique:** (BUNDLE_CODE)

| Coluna | Tipo | Null | Finalidade | Valores | Ref |
|---|---|---|---|---|---|
| 🔑 `BUNDLE_ID` | varchar(36) | N | PK UUID do bundle. |  |  |
| `BUNDLE_CODE` | varchar(255) | N | Código do bundle de i18n. |  |  |

**Relacionamentos (saem desta tabela):**

- `(BUNDLE_ID)` → **I18N_LOCALE** `(BUNDLE_ID)` · 1:N · physical-fk/confirmed — Locales do bundle.
- `(BUNDLE_ID)` → **I18N_RELATED_BUNDLE** `(BUNDLE_ID)` · 1:N · physical-fk/confirmed — Bundles relacionados.

**Dicas de consulta:** Hierarquia: BUNDLE -> LOCALE -> LITERAL_TRANSLATED.

## I18N_RELATED_BUNDLE

Lista os bundles relacionados (por código) a um bundle, para herança/fallback de literais.

**Ciclo de vida:** Configuração; baixo volume.

**Atenção:** RELATED_BUNDLE_CODE é código textual, não FK para I18N_BUNDLE.BUNDLE_ID.

**PK:** RELATED_BUNDLE_ID

| Coluna | Tipo | Null | Finalidade | Valores | Ref |
|---|---|---|---|---|---|
| 🔑 `RELATED_BUNDLE_ID` | varchar(36) | N | PK UUID do relacionamento. |  |  |
| `BUNDLE_ID` | varchar(36) | N | Bundle que declara a relação. |  | I18N_BUNDLE.BUNDLE_ID |
| `RELATED_BUNDLE_CODE` | varchar(255) | N | Código do bundle relacionado (compara com I18N_BUNDLE.BUNDLE_CODE). |  | I18N_BUNDLE.BUNDLE_CODE |

**Relacionamentos (saem desta tabela):**

- `(BUNDLE_ID)` → **I18N_BUNDLE** `(BUNDLE_ID)` · N:1 · physical-fk/confirmed — Bundle dono (RelatedBundle.bundle).
- `(RELATED_BUNDLE_CODE)` → **I18N_BUNDLE** `(BUNDLE_CODE)` · N:1 · logical-probable/probable — Bundle referenciado pelo código.

**Dicas de consulta:** Resolver relacionado via join por BUNDLE_CODE.
